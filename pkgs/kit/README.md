# @canmi/kit

The design foundation the author's sites share: light and dark (`@canmi/kit/theme`), the design
tokens (`@canmi/kit/tokens/*`), motion, small page behaviors (`@canmi/kit/behavior/*`) and length
units. `svelte` and `@stylexjs/stylex` are optional peers, needed by the parts that use them.

Versioned by the day it was released, `YYYY.MDD.N`; see the repository's `spec/repository.md`.
